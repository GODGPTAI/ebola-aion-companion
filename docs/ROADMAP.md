# EBOLA AION Companion Roadmap

1. **v0.1** Flutter shell, four models, safe mock SDK, external existing-account links, debug APK CI (this source package).
2. **v0.2** Secure authenticated app session and server-issued short-lived tokens; actual licence REST integration with tested recovery/replacement; explicit consent gates.
3. **v0.3** Read-only Bluetooth discovery and firmware compatibility test with G2 hardware, followed by G4, G3, G1. Android 12+ runtime Bluetooth permissions, opt-in recording and no permission abuse.
4. **v0.4** User-approved camera/audio capture and integrity-checked transfers into the existing per-user AES-256-GCM Secure Vault; only remove local originals after verified receipt.
5. **v1.0** Store-ready signed release builds, privacy policy, product compatibility reports, hardware attestation where supported, customer support and warranty flow.
